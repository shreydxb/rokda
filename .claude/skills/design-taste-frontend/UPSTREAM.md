# Upstream

A copy of the `taste-skill` skill from https://github.com/Leonxlnx/taste-skill
(MIT, see `LICENSE`), commit `63aba5f43b5056758b15bbe7d683da8c86a7a7ad` (v2.1.3), unchanged.

It is copied rather than installed as a plugin because cloud sessions do not
install plugins enabled in `.claude/settings.json`, and a copy only changes when
someone updates it here. To update: clone upstream, read the diff, and replace
this folder with its `skills/taste-skill`, keeping this file and `LICENSE`.
