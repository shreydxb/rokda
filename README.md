# Rokda

A private household finance app — net worth, cash flow, budgets, investments, and planning in one place. Built with Vite + React + Supabase.

Implements the "Our Money — Command Center v2" design (Direction A · Private Ledger). Independent from any prior project; started from scratch.

## Stack

- Vite + React
- Supabase (Postgres, Auth, RLS)
- react-router-dom

## Development

```bash
npm install
npm run dev
```
